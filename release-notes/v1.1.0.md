Teen Health & Wellness Showdown v1.1.0 brings the new game from the website and the new logo. Like earlier versions, it's free, fully offline, and requests no Android permissions, with no ads, accounts, tracking, or internet. The App ID (com.wgra.teenhealthshowdown) is unchanged.

## ⚠️ Uninstall the old version first
This release is signed with a **new WGRALGO release key**. Android will not install it over v1.0.5 or older. If you have an older version installed, **uninstall it first**, then install this one. The app saves no data, so uninstalling loses nothing. Future updates will install over v1.1.0 normally.

## What's new
- **Setup screen:** name both teams, pick the topics that match today's lesson, choose ages 10–12 or 13–18, game length, one game or best of 3, and sound on or off.
- **New bank for ages 10–12:** 150 simpler questions (with *Growing up & puberty* instead of sexual health), alongside the 300-question teen bank.
- **Timer and steals:** 20 seconds per question (25 for ages 10–12). A wrong answer gives the other side 5 seconds to steal. Unanswered questions come back later, and questions don't repeat until the topic pool is used up.
- **Fairer play:** each side sees the answers in a different order, and answers count on first touch.
- **Pause, restart, and sound effects.** The Android back button pauses the game.
- **New logo:** big on the app icon, the splash screen, and the setup screen, all on black with no white box.
- **Full-screen app layout:** the game fills the tablet screen. Tips for teachers and crisis lines (988, The Trevor Project) are in How to Play.
- Version 1.0.5 → 1.1.0 (versionCode 6 → 7).
